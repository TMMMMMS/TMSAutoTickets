# 开售购票中的人工验证等待

## Purpose

定时购票在用户打开官方购买入口后保留本次会话，让用户有时间完成大麦要求的人工验证，并在官方应用进入目标演出选票页时核对场次。

## ADDED Requirements

### Requirement: 进入场次列表前等待人工验证

系统 SHALL 在定时购票首次进入或重新进入选票页的过程中，对已识别的安全验证界面给出人工操作提示，等待时间受当次购票截止时间约束。

#### Scenario: 验证占用超过普通页面等待时间

- **WHEN** 点击购买后安全验证持续超过 8 秒，随后大麦在有效窗口内经详情页短暂过渡到目标场次列表
- **THEN** 程序提示一次，等待期间仅观察页面，继续在原会话核对演出和场次，购买入口点击次数为一次

#### Scenario: 用户取消或窗口到期

- **WHEN** 验证等待中用户取消或当次购票截止时间已到
- **THEN** 程序报告对应原因并停止，用户可继续手动操作手机

#### Scenario: 普通跳转或其他阻塞

- **WHEN** 未出现可识别的验证界面，选票页直接出现、跳转至其他演出、要求登录或普通页面等待超时
- **THEN** 程序分别执行已有的目标检查和相应停止逻辑，只有匹配目标才可选票

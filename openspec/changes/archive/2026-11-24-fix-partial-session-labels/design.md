# 场次行补读设计

## Context

真机上的场次行显示日期、时间和“预售”，其可访问性节点仅提供“预售”。现有 Vision 读取器对同一区域可识别出完整内容。

## Goals / Non-Goals

范围限于 Android V2 选票页的场次读取与回归测试。票档匹配、购票配置、观演人选择和订单提交均在本次变更范围之外。

## Decisions

- 在场次读取处判断控件文字是否提供配置所需的日期信息，以及用户指定的时间信息。字段完整的场次直接交给现有匹配器，日期或时间明确不同的完整场次正常排除。
- 对信息不足的候选行复用现有稳定行边界和 Vision 批量读取逻辑，保留已知的日期、时间、库存标记和控件可用状态。只在同一行内补充信息，原文和识别值冲突时禁止选中该行。
- 沿用现有场次唯一性检查。旧配置省略时间时按日期唯一匹配。

## Risks / Trade-offs

截图识别会增加耗时，仅对需要补读的行执行。识别失败或无法确定唯一目标时应停在选票步骤。

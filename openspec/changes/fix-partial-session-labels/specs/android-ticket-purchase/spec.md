# 安卓场次识别

## Purpose

在安卓真机选票时，根据用户配置的演出日期与开场时间核对页面上的每个候选场次，即使控件文字只包含预售或缺货状态，也能利用同一选项中可见的信息判断场次。

## ADDED Requirements

### Requirement: 补读场次行中缺失的演出日期和时间

系统 SHALL 从同一场次行读取配置所需的日期与时间，仅在能够唯一确认可购目标时选择该行。

#### Scenario: 厦门站只暴露预售标签

- **WHEN** 控件只提供“预售”，同一行显示“2026-11-28 周六 19:00 预售”，配置要求该日期与时间且只有该行匹配
- **THEN** 系统识别并选择该场次，继续核对票档

#### Scenario: 同日多个场次

- **WHEN** 控件可读日期但缺少配置要求的时间，同日场次分别显示 14:00 和 19:00
- **THEN** 配置为 19:00 时只选择显示 19:00 的场次

#### Scenario: 无法唯一确认

- **WHEN** 补读后仍无法确定目标行，或多行匹配同一目标
- **THEN** 系统停止选票并提示核对，不点击场次

#### Scenario: 目标场次缺货

- **WHEN** 补读可确认目标场次且原控件标记缺货或不可操作
- **THEN** 系统按已有缺货流程处理该场次
